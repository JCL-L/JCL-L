# NinOne 手动模式工控机部署配置说明

版本：2026-09-09 v16，Release / x86 / .NET Framework 4.8

## 1. 安装顺序

1. 将整个部署包解压到本机可写目录。只有 C 盘时可使用 `C:\NinOneManual`；也可以放在其他盘。不要只复制 EXE，也不要放入 `Program Files`。
2. 确认 Windows 已启用或安装 .NET Framework 4.8。
3. 安装 Microsoft Visual C++ 2013 Redistributable x86。即使系统是 64 位，也必须安装 x86 版本。微软官方下载页：`https://www.microsoft.com/zh-CN/download/details.aspx?id=40784`。
4. 安装实际使用的 ZLG CANFD 100U 或 200U Windows 设备驱动。应用所需的 x86 运行 DLL 已在 `App\vendor\ZlgCan\x86` 中，Windows 设备驱动仍须单独安装。
5. PA333H 使用 USB 接口时，运行 `Setup\Drivers\PA333H\installer_x86.exe`。GPD2303S、GDM9061 若通过 USB 转串口连接，应安装所用转换器对应的驱动。
6. 完成下面的网络、串口和系统设置，然后运行 `运行现场预检.cmd`。
7. 预检通过后运行 `启动NinOne手动模式.cmd`，按现场验收顺序逐台连接、逐项操作。

## 2. 工控机软件要求

- Windows 10/11，64 位系统可以使用；本程序固定以 x86 进程运行。
- .NET Framework 4.8 或更高的 4.x 版本。
- Microsoft Visual C++ 2013 Redistributable x86，ZLG DLL 直接依赖 `MSVCR120.dll` 和 `MSVCP120.dll`。
- PLC 由程序内置的 S7 客户端通过 TCP 102 直连，不需要安装或授权 NI OPC Servers。
- 程序为免安装目录部署，不使用数据库；PLC、N69206、示波器的 IP/端口、串口、CAN 连接参数和 N69206 四模式量程均在对应页面设置，运行日志为本地文本。

## 3. 工业网口

给连接 PLC、电子负载和示波器的独立网卡设置静态 IPv4：

| 项目 | 设置 |
|---|---|
| 工控机 | `192.168.4.100` |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | 留空，除非现场网络方案另有要求 |
| DNS | 留空 |
| PLC | `192.168.4.101` |
| N69206 | `192.168.4.102:7000` |
| ZDS2024C Plus | `192.168.4.128:5025` |

关闭该网卡的 DHCP 和“允许计算机关闭此设备以节约电源”。Windows 防火墙应允许本程序在专用网络运行，并允许到 TCP 102、7000、5025 的出站连接。检查网段内不存在重复 IP。

## 4. S7 直连 PLC

1. 工控机网卡地址为 `192.168.4.100`，PLC 地址为 `192.168.4.101`，端口为 TCP 102；这些值在 PLC 页面顶部显示，点击“连接”时应用。
2. 现场已执行 `Test-NetConnection 192.168.4.101 -Port 102` 并得到 `TcpTestSucceeded: True`。
3. 程序连接时先只读 Q0.0 和 Q8.0 验证 S7 协议，不会自动改变输出。
4. 继电器映射严格来自已确认的 OPF：K1～K8 对应 Q0.0～Q0.7，K9～K16 对应 Q8.0～Q8.7。
5. K3～K7 开启前仍有二次确认；所有写入均执行写后回读；退出时按 K16 到 K1 关闭。

现场日志已确认 PLC 为 S7-200 SMART，因此默认 `System.ini` 使用 `PLC.S7.CPU类型="S7200Smart"`。`System.ini` 只保留 CPU 类型、机架/槽位、TSAP 和超时等高级参数，不再保存任何 IP 或端口。更换 PLC 后可改为 `Auto` 或 `S7200`；传统 S7-200/CP243-1 使用了非默认 TSAP 时，再填写 `PLC.S7.本地TSAP` 和 `PLC.S7.远端TSAP`。TSAP 格式例如 `10.00`。

## 5. 串口

在设备管理器的端口高级设置中固定端口号；设备更换 USB 插口后要再次核对。

现场预检会合并 64 位/32 位 .NET、注册表和设备管理器的串口枚举结果。脚本只列出现有串口及其来源，不再按 INI 中的固定 COM 号判断缺失。个别 USB 串口驱动可能被某一种枚举方式漏掉；只要 NinOne 能完成 `*IDN?` 并收到正确设备型号，就以程序实际通讯成功为准。

| 设备 | 界面默认值 | 参数 | 结束符 |
|---|---:|---|---|
| GPD2303S | COM12 | 9600，8N1，无流控 | CRLF |
| GDM9061 | COM13 | 115200，8N1，无流控 | CRLF |
| PA333H | COM4 | 115200，8N1，无流控 | LF (`0x0A`) |

三个设备的 COM 号均使用可下拉选择、也可手输的组合框，已确认的 COM12、COM13、COM4 作为各自默认值；波特率也在页面选择。点击“连接”时应用，不从 `System.ini` 读取。PA333H 源侧/输出侧通道也在界面选择，默认 CH1/CH3。仪器端串口设置必须与界面一致。程序按 PA300 系列 SCPI 手册使用 LF 结束命令。关闭 Windows 的 USB 选择性暂停，并固定使用同一物理 USB 插口。

PA333H 页面可以一次读取，也可以选择 250/500/1000/2000 ms 间隔连续读取。连续读取运行在异步任务中，界面仍可操作；断开设备或退出程序前会先停止连续读取。

GDM9061 的量程由下拉框选择。下拉内容会随 DCV、ACV、DCI、ACI、电阻等功能切换，不能手输任意量程。

GPD2303S 页面包含独立的“辅助电源开关时间记录”，不会与原始串口日志混合。手动输出和循环输出每次通过 `STATUS?` 回读确认后，以 `yyyy-MM-dd HH:mm:ss.fff` 格式显示 ON/OFF 时间。页面的“循环关断功能”可分别设置 ON、OFF 持续时间，单位为 ms；“启动循环”只启动循环任务，原来的“输出 ON/OFF”用于单次手动控制。停止循环、断开辅助电源或退出程序时会先停止循环并关闭输出。设置的持续时间从状态回读确认后开始计算，实际切换周期还包含 9600 波特率串口传输和 `STATUS?` 回读时间，因此该功能不是硬实时脉冲源。

GPD 的 `ISET1/ISET2` 是 CH1/CH2 的电流上限设定，范围 0～3 A；程序写入后使用 `ISET1?/ISET2?` 回读确认。设备没有另一个限流启用/关闭命令，因此界面显示“电流上限 (ISET)”，不提供独立限流开关。

“电压升降循环”可选择 CH1/CH2；上升目标和下降目标范围为 0～30 V，上升目标必须大于下降目标；上升/下降速率范围为 0.001～30 V/s，循环次数范围为 1～100000。启动后程序先从当前 VSET 按对应速率运行到下降目标，再执行指定次数的“下降目标→上升目标→下降目标”。每一步只写入并回读所选通道的 VSET，不修改 ISET，也不自动改变输出 ON/OFF。停止按钮保持最后一次确认的电压；正常完成停在下降目标。需要带载升降时，由操作员先使用单次“输出 ON”。循环关断和电压升降不能同时运行。该功能按实际经过时间修正设定值，但仍受串口传输、设备响应和 0.001 V 命令分辨率影响，不是硬实时斜坡源。

## 6. N69206

- 页面默认地址：`192.168.4.102:7000`，设备 ID 默认 160；连接前可修改，点击“连接”时应用。
- 通讯：Modbus RTU 报文经 TCP 传输
- 应用负责远程模式、CC/CV/CR/CP 参数和输入开关；现场先确认页面 IP、端口及设备 ID 与负载实际设置一致。
- CC/CV/CR/CP 各有独立量程下拉框：`0`=大量程、`1`=小量程、`2`=中量程，默认四项均为 `0`。量程不再从 `System.ini` 读取。
- 电流、电压、电阻、功率、Rise/Fall Slew 和 V-Rate 也在界面填写或选择。CV 的 V-Rate 可选 FAST、NORMAL、SLOW、UserDefined；UserDefined 值必须为 0.01～10 V/ms。
- 应用切换模式前会先关闭负载输入。应用参数后需要操作员再次点击“加载 ON”。

## 7. CAN

- 页面名称为“CAN”。设备型号可选 ZLG CANFD 100U（设备类型 42、CAN0 单通道）或 ZLG CANFD 200U（设备类型 41、CAN0/CAN1 双通道）。Vector VN1640A 只保留选项，本版选择后会明确提示尚未实现。
- 设备索引、CAN/CAN FD 模式、仲裁波特率、CAN FD 数据波特率和 120Ω 终端电阻均在页面设置，不从 INI 读取。界面单位统一为 kbps；默认值是 200U、索引 0、经典 CAN、500 kbps、120Ω 开启。
- “连接适配器”只打开 ZLG 设备，并先预配置 CAN0/CAN1 波特率，不自动启动通道。之后可点击“打开选中通道”，也可点击“同时打开全部通道”启动 CAN0 和 CAN1；两个通道可分别发送和接收。
- 适配器配置、连接操作与通道操作分行显示。每个小区域中的选项、状态和按钮按可用宽度平均排列。
- 100U/200U 属于 CAN FD 硬件。页面选择“CAN”时，程序把通道协议设为经典 CAN，同时仍以 CAN FD 硬件类型初始化，这是 ZLG 官方接口的要求。页面选择“CAN FD”时把通道协议设为 CAN FD。
- CAN FD 模式下，单帧发送可选“CAN FD 帧”和“BRS 数据段加速”；仲裁段使用仲裁波特率，BRS 数据段使用数据波特率。
- 本版暂不显示或执行 DCDC 控制与模板组发送，退出程序也不会自动发送 DCDC 关闭帧。
- 打开任一 CAN 通道后，“CAN 收发帧”区域会自动持续接收全部已打开通道，并把本程序成功发送的帧一起显示。可按通道、十六进制 ID 和方向 TX/RX 筛选；“清空收发记录”不会停止接收。
- 每行包含毫秒时间、TX/RX、CAN0/CAN1、标准/扩展帧、ID、长度和数据。旧格式 `S000007FF` 中的 `S` 表示标准帧，并非 ID 的一部分；新版显示为“标准帧 ID=7FF”。
- 单帧 Data 可直接连续输入，例如 `0102030405060708`，也兼容空格、逗号和 `0x` 前缀。数据长度独立设置；输入不足时尾部补 00，输入超过长度时拒绝发送。
- 发送间隔填写 0 时点击按钮只发一次；填写大于 0 的毫秒数时开始循环发送，点击“停止循环发送”结束。循环发送期间锁定通道、ID、Data、长度、间隔和帧类型，避免运行中参数发生变化。
- 应用设置适配器 120Ω 终端电阻；现场仍需检查总线两端终端配置，避免缺少或重复终端。插入适配器后，设备管理器不得显示黄色感叹号；预检应能枚举 CANFD/USBCAN 设备。
- v12 直接使用官方 `zlgcan.dll` 发送接口，并修正 CAN FD 硬件类型、经典 CAN 协议属性和 120Ω 初始化顺序。发送返回 0 时通道保持打开，不会自行关闭；日志会记录设备状态、ZLG 错误码、REC、TEC 和 ECC。检查接收端通道已启动、CAN-H/CAN-L/GND 接线、两端终端、两台电脑的波特率和 CAN/CAN FD 模式一致。

## 8. ZDS2024C Plus

- 页面默认 LAN 地址：`192.168.4.128:5025`，连接前可修改。
- 开启 LAN/SCPI 远程控制。
- 示波器 IP 和端口在页面顶部填写，点击“连接”时应用，不从 `App\config\System.ini` 读取。
- 时基、时基模式、水平偏置、采集模式、平均次数、滚动模式以及 CH1～CH4 的启用、耦合、带宽限制、探头类型、探头倍率、垂直档位、垂直偏置和反相均在示波器页面设置；点击“应用界面参数”后发送到设备。
- 采样深度按现场要求固定为 14000 点，并在界面显示。
- “读取多通道波形”会保存 WFM，并把示波器当前多通道屏幕显示在页面内；“截图”也会更新该显示区并保存 BMP。

## 9. 电源策略与目录权限

- 使用“高性能”电源计划，关闭自动睡眠、休眠、USB 选择性暂停。
- 关闭工业网卡和 USB Root Hub 的节能关断选项。
- `App` 目录必须允许当前操作员写入，以便保存日志。
- 启动和预检脚本使用部署包自身的相对路径，不要求工控机存在 D 盘。
- 杀毒软件如拦截厂商 DLL，应由现场管理员按文件哈希和来源建立白名单，不能删除 `App\vendor` 内容。

## 10. 首次现场验收

各设备页面会横向、纵向填满工作区，对应日志位于右侧并默认展开。CAN 页面右侧同时显示收发帧和原始 CAN 日志；示波器页面仍以波形显示区为主体。设备页滚动区域被约束在当前可见工作区内，滚动条轨道不会越过页面底部；右侧日志框随剩余高度伸展。窗口最大化时，整个界面以统一比例放大，包括导航、文字、按钮、输入框、日志和波形显示。

1. 保持高压直流源关闭，先运行预检。
2. 单独连接 PLC。在页面核对本机 IP、PLC IP 和端口，再点击连接和读取；确认 16 点状态正确后逐点核对 K1～K16，重点确认 K3～K7 后再带负载。
3. 在 GPD2303S、GDM9061、PA333H 页面从下拉框选择设备管理器显示的 COM 号和仪器波特率，再分别连接各设备，检查连接状态、读数和原始通讯日志。
4. 在 GPD2303S 页面设置安全的 ON/OFF 毫秒时间并启动循环，确认独立记录区按毫秒显示每次开关；停止后确认输出关闭。
5. 在输出关闭时先测试 GPD 电压升降循环：选择通道，使用较小电压范围、较低速率和 1 次循环，核对 VSET 查询值按速率变化并最终停在下降目标。再按现场安全条件输出 ON，确认实际输出电压变化；中途停止时确认保持最后一次电压，且 ISET 和输出状态没有被程序改变。
6. 在 CAN 页选择 200U、索引 0、现场模式和 kbps 波特率，先“连接适配器”，再点“同时打开全部通道”。从另一台电脑分别向 CAN0/CAN1 所接总线发送，确认收发区自动显示对应通道。Data 连续输入 `0102030405060708`、长度 8、间隔 0 验证单次发送；再用安全间隔验证循环发送和停止。分别按通道、ID、TX/RX 筛选并核对结果，然后独立关闭、重新打开两个通道，断开再连接一次，确认没有旧通道误报。最后检查 CAN FD/BRS（现场总线支持时）和 120Ω 设置。
7. 执行退出测试，确认关闭顺序包括示波器停止、N69206 输入关闭、GPD 自动任务停止和输出关闭、K16 到 K1 依次释放，并确认未额外发送 DCDC CAN 报文。
8. 高压直流源仅人工操作并在现场记录。

预检仅做只读检测，不会控制继电器或仪器。没有接入真实设备时出现“缺失/不通”是预期结果，不代表程序包损坏。
