## v15 CAN 双机互测、收发筛选、循环发送及既有功能现场复验

- [ ] CAN：选择 ZLG CANFD 200U、设备索引 0、CAN、500 kbps、120Ω；点击“连接适配器”后确认已连接但“已打开”为“无”，再点击“同时打开全部通道”，确认状态同时显示 CAN0、CAN1。
- [ ] CAN：操作通道选择 CAN0，发送 ID 234、8 字节单帧并确认发送成功；再选择 CAN1 发送同一帧并确认成功。分别保存 TX/RX 和原始 CAN 日志。
- [ ] 双机互测：发送电脑和接收电脑均选择经典 CAN、500 kbps；接收端先启动对应通道。核对 CAN-H 对 CAN-H、CAN-L 对 CAN-L、GND 对 GND，总线两端各保留一个 120Ω。
- [ ] 自动接收：本程序打开 CAN0/CAN1 后不操作任何接收按钮，从另一台电脑连续发送，确认“CAN 收发帧”区域实时显示 CAN0/CAN1、ID、长度和数据，原始日志同步出现 RX。
- [ ] 收发合并与筛选：本程序分别从 CAN0/CAN1 发送，再由另一台电脑回发；确认同一框内同时有 TX/RX，并分别按通道、ID、方向筛选。清空收发记录后接收任务应继续运行。
- [ ] 帧标识：标准帧 ID `7FF` 应显示为“标准帧 ID=7FF”，不再显示易误读的 `S000007FF`；扩展帧应明确显示“扩展帧 ID=…” 。
- [ ] 数据输入：分别输入 `0102030405060708`、`01 02 03 04 05 06 07 08`，数据长度设为 8，确认发送内容相同；长度设为 8、只输入 4 字节时确认尾部补 00。
- [ ] 发送间隔：间隔设为 0，确认每次点击仅发一帧；间隔设为安全的非零毫秒数，确认持续发送、累计数增加，点击“停止循环发送”后停止。
- [ ] CAN：故意在接收端停止通道后发送一次；即使发送返回 0，发送端 CAN0/CAN1 仍应显示打开，不得自行关闭。恢复接收端后再次发送。
- [ ] CAN：分别关闭、重新打开 CAN0/CAN1；再断开适配器、重新连接，确认旧通道立即清空，不再误报“CAN0/CAN1 已处于打开状态”。
- [ ] CAN：断开后改选 ZLG CANFD 100U，确认通道列表只有 CAN0；使用单帧和循环发送复验，确保更换设备后经典 CAN 报文仍可发送。
- [ ] CAN FD：在安全的 CAN FD 总线上选择 CAN FD，分别核对仲裁波特率、数据波特率、普通 FD 帧和 BRS 数据段加速帧；保留原始 TX/RX 日志。
- [ ] CAN：确认 Vector VN1640A 可见但选择后会明确提示“待实现”，本版不做 Vector 真机验收。
- [ ] GPD2303S、GDM9061、PA333H：分别在设备页面填写实际 COM 号与波特率再连接；确认删除 INI 串口项后仍能正常识别和通信。
- [ ] PA333H：在界面选择源侧/输出侧通道并应用，确认六项读数对应所选通道。
- [ ] 预检：确认脚本只列出系统实际枚举到的串口及来源，不再按 COM12/COM13/COM4 固定值报告“不存在”。
- [ ] 配置文件：确认 `System.ini` 不包含 IP、端口、串口、CAN 连接参数或 N69206 量程，5615 `cfg.ini` 不包含条码、上一工位、产品类型、气缸或 CAN 配置。

- [ ] GPD2303S：分别执行手动“输出 ON”和“输出 OFF”，确认独立开关时间记录区分别新增 ON/OFF，格式精确到毫秒，且不混入原始串口日志。
- [ ] GPD2303S：设置安全的 ON/OFF 持续时间（ms），点击“启动循环”，确认按 ON→OFF 重复切换；启动键不影响单次手动按钮的含义。
- [ ] GPD2303S：循环运行时点击“停止循环”，确认循环结束且输出 OFF；分别复验循环中断开设备和退出程序的安全关闭。
- [ ] GPD2303S：核对记录时间是 `STATUS?` 回读确认时间；周期允许包含串口传输和回读耗时。确认电流项标为“电流上限 (ISET)”，分别写入安全值并确认 `ISET1?/ISET2?` 回读一致；页面没有另一个独立限流开关。
- [ ] GPD2303S 电压循环：输出 OFF，选择 CH1，下降目标 12 V、上升目标 13 V、上升/下降速率 0.5 V/s、循环 1 次；确认先到 12 V，再按约 2 秒上升到 13 V并下降到 12 V，最终 VSET 为 12 V。
- [ ] GPD2303S 电压循环：在现场允许带载后输出 ON，以安全目标和速率重复测试；确认只改变所选通道 VSET，另一个通道、ISET 和输出 ON/OFF 状态保持不变。
- [ ] GPD2303S 电压循环：设置循环 3 次，确认完成数为 3；中途点击停止，确认保持最后一次已回读电压。循环关断运行时电压循环不能启动，电压循环运行时循环关断不能启动。

- [ ] 逐页检查 PLC、GPD2303S、N69206、GDM9061、PA333H、CAN、示波器和高压人工记录：对应日志应在右侧默认展开，并随窗口高度伸展；滚动条轨道必须完整位于当前可见页面内。
- [ ] CAN 页面右侧应同时显示收发帧和原始 CAN 日志；适配器操作与通道操作分行，同一小区域内的控件平均排布；示波器页面应保留波形主体并显示右侧原始 TCP / SCPI 日志。
- [ ] 最大化窗口后逐页检查：页面应填满内容区，导航、字体、按钮、输入框、间距、日志、CAN 接收区和示波器波形应按相同比例放大，不能只扩大空白区域。

- [ ] PLC/N69206/示波器：分别修改一次页面 IP/端口再恢复默认值，确认点击连接使用当前页面值；连接成功信息显示当前目标地址。
- [ ] N69206：在页面逐项选择 CC/CV/CR/CP 量程并用安全的小设定值核对主参数；确认修改量程后点击“应用模式参数”立即使用当前选择，不读取 INI。
